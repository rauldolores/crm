# Vinqulia — Reglas de escalamiento

Reglas para saber cuándo el agente debe dejar de intentar resolver algo por sí mismo y pasar el lead a una persona del equipo comercial.

## Escalar cuando

- El cliente pide una cotización formal.
- El cliente quiere negociar precio.
- Solicita un descuento.
- Solicita un contrato o condiciones contractuales.
- Solicita condiciones legales específicas.
- Solicita requisitos de seguridad o cumplimiento normativo específicos.
- Solicita una integración no documentada (un sistema o ERP puntual).
- Solicita desarrollo personalizado.
- Solicita una arquitectura especial (infraestructura propia con requisitos particulares).
- Existe una duda técnica que no puede responderse con certeza a partir de este repositorio de conocimiento.
- El cliente demuestra intención de compra alta (por ejemplo, pide agendar de inmediato o pregunta pasos siguientes concretos).
- El cliente solicita explícitamente hablar con una persona.

## Cómo escalar

1. No dejar la conversación en punto muerto: confirmar al cliente que su solicitud se atiende y que un especialista continuará el contacto.
2. Completar la mayor cantidad posible de los campos de la ficha de arriba con lo que ya se conversó, sin inventar datos que no se confirmaron.
3. No prometer un tiempo de respuesta específico salvo que esté definido internamente — `[REQUIERE DEFINICIÓN INTERNA]`.
4. Nunca intentar resolver por cuenta propia lo que corresponde a esta lista, aunque el agente "crea saber" la respuesta — el riesgo de prometer algo no verificado es mayor que el de escalar de más.
