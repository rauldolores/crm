# VINQULIA — BASE DE CONOCIMIENTO COMERCIAL

## 1. Identidad del producto

Vinqulia es un sistema CRM para equipos comerciales que permite centralizar clientes, empresas, contactos, oportunidades, tareas, comunicaciones y seguimiento comercial en una sola plataforma.

Vinqulia está diseñado para empresas que necesitan ordenar y profesionalizar su proceso de ventas sin verse obligadas a adoptar un CRM excesivamente complejo, rígido o costoso.

El objetivo principal de Vinqulia es transformar una operación comercial dispersa —Excel, WhatsApp, correo electrónico, llamadas, notas y múltiples herramientas— en un proceso comercial centralizado, visible, medible y automatizable.

Vinqulia forma parte del ecosistema tecnológico de Kontrolia.

El sistema puede utilizarse como servicio gestionado por Kontrolia o desplegarse en infraestructura propia de la empresa cuando sus políticas, requisitos técnicos o necesidades de control de datos lo requieran.

Vinqulia también puede evolucionar hacia soluciones de automatización, integraciones y agentes de inteligencia artificial mediante el ecosistema Kontrolia.

Sitio oficial:
https://www.vinqulia.com/

# 3. Problemas que Vinqulia resuelve

## Problema: cada vendedor trabaja con su propio Excel

Cuando cada vendedor mantiene su propia hoja de cálculo, la empresa pierde visibilidad sobre la operación comercial.

Los datos pueden estar desactualizados, duplicados o ser inaccesibles para otros miembros del equipo.

Vinqulia centraliza los contactos, empresas y oportunidades para que el equipo trabaje sobre una misma fuente de información.

---

## Problema: los prospectos llegan por WhatsApp

Muchas empresas reciben una gran cantidad de prospectos mediante WhatsApp.

El problema aparece cuando la conversación queda exclusivamente en el teléfono del vendedor.

Si ese vendedor está ocupado, abandona la empresa o simplemente olvida dar seguimiento, la empresa puede perder la oportunidad.

Vinqulia permite integrar WhatsApp mediante Twilio y registrar las conversaciones dentro del historial del contacto.

---

## Problema: los seguimientos dependen de la memoria

Un vendedor puede decir:

"Le llamo la próxima semana."

Pero si no existe una tarea o recordatorio, la oportunidad puede enfriarse.

Vinqulia permite crear tareas con responsable y fecha de vencimiento.

Además, sus automatizaciones pueden crear tareas automáticamente cuando ocurre un evento comercial.

Ejemplo:

"Cuando se cree una oportunidad, crear una tarea para enviar la propuesta en un día."

---

## Problema: la información está repartida

Una empresa puede tener:

- Contactos en Excel.
- Correos en Outlook o Gmail.
- Conversaciones en WhatsApp.
- Información comercial en un ERP.
- Notas en documentos.
- Seguimientos en agendas personales.

Esto genera una visión fragmentada del cliente.

Vinqulia busca concentrar la información comercial en una ficha única del contacto o empresa.

---

## Problema: la dirección no sabe realmente cómo va el pipeline

Cuando la información está repartida entre vendedores, el director comercial depende de reportes manuales.

Preguntas como:

- ¿Cuánto tenemos en oportunidades?
- ¿Qué ventas están por cerrar?
- ¿Qué vendedor tiene más oportunidades?
- ¿Qué oportunidades llevan demasiado tiempo estancadas?
- ¿Por qué estamos perdiendo ventas?
- ¿Cuál es nuestra tasa de conversión?

pueden requerir revisar múltiples archivos.

Vinqulia proporciona un pipeline centralizado e informes comerciales para responder estas preguntas.

---

## Problema: el CRM actual es demasiado complejo

Algunas empresas ya utilizan un CRM, pero consideran que:

- Es demasiado complicado.
- Tiene demasiadas funciones que no utilizan.
- Requiere demasiada configuración.
- Es demasiado rígido.
- No se adapta a su proceso.
- Es demasiado caro.
- El equipo comercial no lo utiliza correctamente.

Vinqulia busca ofrecer una alternativa más adaptable a la operación real de la empresa.

# 10. WhatsApp

Vinqulia puede integrarse con WhatsApp mediante Twilio.

Esto permite enviar mensajes desde la ficha del contacto y registrar la conversación en el historial.

El beneficio comercial es que la comunicación deja de depender exclusivamente del teléfono personal del vendedor.

La conversación pasa a formar parte del historial comercial de la empresa.

Importante:

Cuando un prospecto pregunta si Vinqulia "tiene WhatsApp", la respuesta correcta es:

**Sí. Vinqulia puede integrarse con WhatsApp mediante Twilio para enviar mensajes reales desde la ficha del contacto y registrar las conversaciones en el historial.**

No afirmar que Vinqulia incluye gratuitamente una cuenta o número de WhatsApp Business si el usuario no lo ha especificado.

---

# 11. Correo electrónico

Vinqulia permite gestionar comunicación por correo electrónico desde la ficha del contacto.

El sistema utiliza Reply-To inteligente para que las respuestas puedan asociarse automáticamente con el contacto correspondiente.

También puede capturar correo entrante mediante copia al buzón de Vinqulia y crear o enriquecer la ficha correspondiente.

Beneficio:

El historial comercial deja de depender de revisar manualmente el buzón del vendedor.

# 12. Formularios de captura de leads

Vinqulia puede generar formularios públicos para captar prospectos desde una página web.

El formulario puede utilizarse:

- Como enlace.
- Mediante iframe.
- Dentro de una página web.

Cada envío puede crear un nuevo contacto.

Los formularios incluyen mecanismos anti-spam.

Esto permite crear un flujo:

VISITANTE WEB
→ FORMULARIO
→ CONTACTO
→ OPORTUNIDAD
→ TAREA
→ SEGUIMIENTO
→ NEGOCIACIÓN
→ CIERRE

Este flujo es especialmente importante para empresas que actualmente reciben formularios pero después gestionan los prospectos manualmente.

# 13. Automatizaciones

Vinqulia incorpora automatizaciones basadas en reglas.

El concepto puede explicarse como:

**"Cuando ocurra X, haz Y."**

Ejemplos:

- Cuando se cree un contacto, crear tarea para llamar en 3 días.
- Cuando se cree una oportunidad, crear tarea para enviar propuesta en 1 día.
- Cuando una oportunidad pase a "En negociación", asignarla a un vendedor específico.
- Cuando se cree un lead, asignarlo automáticamente a un responsable.
- Cuando una oportunidad cambie de etapa, ejecutar una acción definida.

Los disparadores disponibles incluyen eventos como:

- Contacto creado.
- Oportunidad creada.
- Cambio de etapa.

Las acciones incluyen:

- Crear tareas.
- Asignar responsables.

Las reglas pueden ejecutarse independientemente de si el dato entró por la aplicación, API o importación.
